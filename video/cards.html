How it is built

Durable Object One per repository: the scopes, the line, and an index of what every file exports and imports. A scope is granted in one step.
Workflow The review as durable steps: contracts, tests, triage, review, and the landing under a lock.
Containers The repository's tests, in a fresh container for each run. No secret inside: a Worker adds the token on the way out.
Artifacts A fork per task, and candidates on hidden refs. dibs builds commits and packfiles itself, and joins shared files.
Workers AI Clef, a small decision model, for the coupling no import shows. It informs, and never decides alone.
Claude The reviewer: it reads the repository, and is told what the tests and the index already checked.

What it does not do, and how to run it

  • The index sees signatures, not behaviour.The tests see behaviour, so a repository without tests has only the reviewer. The index reads TypeScript and JavaScript.
  • pnpm local runs all of it on your machine.No account and no keys: stand-ins take the place of Artifacts, Workers AI and the reviewer.
  • MIT licence.It deploys to your own Cloudflare account with two commands.
